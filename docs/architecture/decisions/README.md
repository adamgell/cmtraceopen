# Reducer Framework decisions

Short architecture decisions for cross-lane reducer semantics.

These decisions govern shared semantic questions. Workload-specific reducers remain responsible for their own state machines and domain rules.

A file named `ADR-NNN-...-revision-N.md` is a proposed revision awaiting a ruling from the repository owner. The ADR it revises stays authoritative until the revision is accepted, amended, or rejected.
